# ⚖️ ContabLab

### Aprender contabilidade praticando.

O ContabLab é uma plataforma de estudos criada para ajudar estudantes de Ciências Contábeis a praticar partidas dobradas de forma interativa e acompanhar os efeitos dos lançamentos.

> **Status:** projeto em desenvolvimento  
> **Objetivo:** tornar a prática contábil mais visual, acessível e didática.

## O que a plataforma oferece

- **Trilha de exercícios:** desafios progressivos, progresso visível e feedback didático.
- **Simulador contábil:** prática de lançamentos a débito e crédito com conferência do equilíbrio.
- **Razonetes:** visualização dos movimentos e saldos das contas em formato “T”.
- **Balancete:** acompanhamento consolidado de movimentos e saldos.
- **Recursos de apoio:** plano de contas didático e guia rápido de partidas dobradas.
- **Progresso individual:** conta de estudante com acompanhamento da experiência de estudo.

## Como funciona

1. Escolha um exercício ou registre um fato contábil no simulador.
2. Pratique os lançamentos e confira débitos e créditos.
3. Veja como os registros afetam os razonetes e o balancete.
4. Use as explicações e o progresso para continuar aprendendo.

## Tecnologias

React · Vite · Tailwind CSS · Node.js · Express · SQLite

## Sobre o projeto

O ContabLab é um projeto independente desenvolvido para apoiar o aprendizado de Ciências Contábeis e explorar a criação de uma aplicação web de ponta a ponta.

A plataforma tem finalidade educacional e não substitui aulas, orientação profissional ou sistemas contábeis oficiais.
